## Setup provenance

FHGM was created as a fork of FAIR-bioHeaders/FHGFF3. This setup starts at
`1bfccedbe444e5a9d9c39ae3e7d1b35e43df77e0`, cloned on 2026-11-05.
The inherited header retains its separately recorded shared-source pin; no
baseline files are relabeled or regenerated by this setup.

- [ ] Coordinate toolkit and website support in linked work after the draft is reviewed.

## Completion criteria for the first design pass

Each proposed requirement has an example or curator rationale, a location (header
or GFF3 feature layer), a comparison with existing FHGFF3 support, and an explicit
validation boundary. Record unknowns rather than filling them with plausible
metadata. No decision is implied by checking a repository-setup task complete.

## Working paths

Use [examples/](examples/README.md) for source-selection and provenance records.
Keep actual retrieved payloads out until reuse terms are inspected. The
[draft model and validator](model/README.md) live separately from the
immutable reference baseline.
